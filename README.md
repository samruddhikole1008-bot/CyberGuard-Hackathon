# CyberGuard – Cybersecurity Threat Detection System

CyberGuard is a hackathon-ready prototype that analyzes suspicious URLs and phishing-style messages. It returns a 0–100 risk score, a risk category, and explainable warning signs.

## Features
- URL risk scanner
- Phishing-message scanner
- Explainable risk scoring
- Responsive dashboard UI
- No API key required

## Technology
Python, Flask, HTML5, CSS3, JavaScript

## Run
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run `pip install -r requirements.txt`.
4. Run `python app.py`.
5. Open `http://127.0.0.1:5000`.

## Future scope
Live threat-intelligence APIs, DNS/domain-age checks, browser extension, stronger ML models, authentication, logging and organization-level reporting.

## Note
This is an educational/hackathon prototype, not a production security product.
